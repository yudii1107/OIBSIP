# YudiCalc — Calculator

A modern, responsive calculator built using HTML, CSS, and JavaScript as part of the Oasis Infobyte SIP Web Development and Designing Internship — Level 2, Task 1.

## Features

- Basic arithmetic operations
- Operator precedence
- Decimal calculations
- Percentage calculation
- Positive and negative number toggle
- Backspace and clear functions
- Keyboard support
- Responsive dark UI with yellow accents

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Run Locally

1. Clone or download this repository.
2. Open the `WebDev-L2-Task1-Calculator` folder.
3. Open `index.html` in your browser.
